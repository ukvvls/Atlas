# ATLAS — AI Study Space (Fresh Repository)

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا.
2. ارفع الملفات الموجودة في هذا المجلد إلى جذر المستودع: `index.html`, `README.md`, `.nojekyll`.
3. افتح Settings → Pages.
4. اختر Deploy from a branch ثم `main` و`/(root)` واضغط Save.
5. افتح الرابط الذي يظهر لك بعد اكتمال النشر.

## إعداد Gemini
1. افتح الموقع → الإعدادات → Gemini AI.
2. أول مرة: اكتب كلمة مرور محلية من 8 أحرف على الأقل، ثم اضغط فتح الإعدادات.
3. أدخل Gemini API Key واحفظ وأغلق.
4. ارجع للرئيسية وارفع PDF نصيًا ثم حلله.

## مهم جدًا عن الأمان والخصوصية
- كلمة المرور تقفل واجهة لوحة Gemini فقط. لا تجعل مفتاح API آمنًا ضد شخص يستطيع فحص المتصفح.
- GitHub Pages موقع ثابت، لذلك استدعاء Gemini يتم من المتصفح. لا تستخدم مفتاحًا عليه فوترة/صلاحيات حساسة في موقع عام. للحماية الحقيقية انقل المفتاح إلى Backend أو Cloudflare Worker.
- لا ترفع مفتاح API داخل المستودع.
- هذه النسخة تحفظ البيانات محليًا في المتصفح. المزامنة السحابية وتسجيل الدخول بين الأجهزة غير مفعّلين؛ يتطلبان إعداد خدمة خلفية وقاعدة بيانات.

## المزايا
- واجهة عربية مع خيار English، وتنقل بين الصفحات.
- خلفية متحركة وانتقالات liquid/glass وأيقونات زجاجية.
- خمس ثيمات: ذهبي، أحمر داكن، أزرق داكن، أخضر داكن، وردي.
- PDF.js لاستخراج النص من ملفات PDF النصية.
- Gemini 2.5 Flash لتوليد فصول ودروس وملخصات وخرائط Mermaid وأسئلة.
- تقدم، XP، اختبار نهائي ورتب.
- ملف طالب، جدول أسبوعي، وقوائم مواد استرشادية للثانوية العامة والأزهرية والإعدادية.

## حدود النسخة
- ملفات PDF المصورة تحتاج OCR وغير مدعومة هنا.
- يتم إرسال أول 90,000 حرف مستخرج إلى Gemini. الكتب الأكبر تحتاج تقسيمًا إلى أجزاء.
- قوائم المواد استرشادية وليست قائمة رسمية كاملة لكل صف وشعبة أو سنة. تحقق من دليل الوزارة/الأزهر الحالي.
- راجع مخرجات الذكاء الاصطناعي بمقارنتها بالكتاب الأصلي.
